# Media Directory

This directory is used to store user-uploaded media files like:
- Video files
- Thumbnails
- Profile pictures

## Structure

The files are organized in subdirectories by type and date:
- `/videos/YYYY/MM/DD/` - Original uploaded videos
- `/thumbnails/YYYY/MM/DD/` - Video thumbnails
- `/profile_pictures/YYYY/MM/` - User profile pictures

This directory is excluded from version control.
